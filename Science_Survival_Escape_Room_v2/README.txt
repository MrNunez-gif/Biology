# Science Survival Escape Room — Version 2

This version changes the activity into a true room-to-room escape experience.

## How it works
- There are 7 different rooms.
- Every room has a different visual background/theme.
- Students solve the challenge in the room.
- A code is revealed only after the challenge is completed.
- Students enter that code to unlock the next room.
- The codes are:
  1. SURVIVE
  2. CAMP
  3. DEFEND
  4. ADAPT
  5. RISK
  6. THINK
  7. ESCAPE

## Rooms
1. The Expedition — mission
2. The Supply Camp — choose and rank five resources
3. The Decision Tent — Claim, Evidence, Reasoning
4. The Storm Lab — adapt to environmental change
5. The Danger Lab — calculate risk
6. The Team Station — compare and rethink
7. The Research Station — final reflection

## Run
Open `index.html` in Chrome/Edge.
